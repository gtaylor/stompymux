StompyMUX is a Rust game server for creating and hosting text-based multiplayer games about Big Stompy Robots.
It combines MUX objects, Lua scripting, SQLite persistence, and a native BattleTech combat system.

## Status

StompyMUX is a clean-room Rust rewrite of the [BattletechMUX](https://sourceforge.net/projects/btonline-btech/) lineage, using the same game directory and aiming for the same user-visible behavior.
Our foundations are built from more than [three decades of contributions](./docs/content/docs/history.md).
The rewrite is pre-1.0; behavior and APIs may change as coverage grows.
See the [Installation](./docs/content/docs/installation.md) guide to get started.
