# StompyMUX documentation site

This Hugo site uses the Docsy theme through a Hugo module. Install the Node
dependencies once for Docsy's PostCSS step, then build or serve it from the
`stompymux-rs` directory with:

```sh
npm --prefix docs ci
just docsite
just docsite-serve
```

The generated `docs/public/` directory is not tracked.

Lua package reference pages are generated by the Cargo `lua-doc-updater` binary
from the Rust-owned LuaLS declarations in `game/lua/types/` and the Rust
constant and error catalogs. After changing those contracts, run
`just update-lua-types` and `just update-lua-docs`. Use `just check-lua-docs`
to verify the checked-in reference.

Examples live outside the generated pages in `docs/lua-examples/`. Give an
example the same path as its API page, with `.lua` instead of `.md`. For example,
`docs/lua-examples/mux/world/type-object/name.lua` appears on the
`Object:name` page. Add explanatory Lua comments in the example file, then run
`just update-lua-docs`. The updater rejects examples without a matching API.
