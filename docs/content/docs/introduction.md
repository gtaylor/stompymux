StompyMUX is a Rust game server for text-based multiplayer games about Big
Stompy Robots. The server combines MUX objects, Lua scripting, SQLite
persistence, and a native BattleTech combat system.

## Status

The Rust codebase is a clean-room rewrite using the same game directory as
the earlier [BattletechMUX](https://sourceforge.net/projects/btonline-btech/)
lineage. It aims for the same user-visible behavior while organizing the
server into Rust domains and adapters. The rewrite is pre-1.0; behavior and
APIs may change as coverage grows. Its history spans
[more than three decades of contributions](/docs/history/).
