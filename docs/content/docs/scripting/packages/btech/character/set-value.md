Set one character value by name or code, preserving the C unsigned-byte storage.

## Signature

```lua
btech.character.set_value(character, value, amount)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `character` | `DbRef\|Object` | Player object. |
| `value` | `string\|integer` | Character-value name or code. |
| `amount` | `integer` |  |

## Returns

No values.
