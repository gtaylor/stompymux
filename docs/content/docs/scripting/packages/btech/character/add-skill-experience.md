Adds experience to one of a character's skills.

## Function

### Synopsis

```lua
btech.character.add_skill_experience( character, skill, amount )
```

### Arguments

`Object character`
: The character.

`string skill`
: The skill name.

`integer amount`
: The signed experience adjustment.

### Returns

None.
