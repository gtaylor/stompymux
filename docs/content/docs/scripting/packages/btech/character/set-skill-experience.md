Sets a character skill's accumulated experience.

## Function

### Synopsis

```lua
btech.character.set_skill_experience( character, skill, experience )
```

### Arguments

`Object character`
: The character.

`string skill`
: The skill name.

`integer experience`
: The new accumulated experience, from 0 through 2,147,483,647.

### Returns

None.
