Publish a wizard-only skill leaderboard without changing XP.

## Signature

```lua
btech.character.xptop(actor, skill)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `actor` | `integer` |  |
| `skill` | `string` | Canonical skill name or alias. |

## Returns

- `table report Skill, counted players, total balance, top sixteen entries and literal text.`
