Returns one script-visible character value.

## Function

### Synopsis

```lua
btech.character.value( character, value )
```

### Arguments

`Object character`
: The character.

`string|integer value`
: The value name or numeric code.

### Returns

`BtechCharacterValue result`
: The definition and current value.
