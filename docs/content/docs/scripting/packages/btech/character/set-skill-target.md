Sets a character skill's target number.

## Function

### Synopsis

```lua
btech.character.set_skill_target( character, skill, target )
```

### Arguments

`Object character`
: The character.

`string skill`
: The skill name.

`integer target`
: The new target number.

### Returns

None.
