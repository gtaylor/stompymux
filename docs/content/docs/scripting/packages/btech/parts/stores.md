Lists every stored part with a nonzero quantity.

## Function

### Synopsis

```lua
btech.parts.stores( target )
```

### Arguments

`DbRef|Object target`
: The stores-bearing object.

### Returns

`BtechPartStack[] stores`
: The stored part records and quantities.
