Sets a part's configured cost.

## Function

### Synopsis

```lua
btech.parts.set_cost( part, cost )
```

### Arguments

`BtechPartRef part`
: A part record, packed ID, or unique name.

`integer cost`
: The new non-negative cost.

### Returns

None.
