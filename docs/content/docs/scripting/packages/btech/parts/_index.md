`btech.parts` provides part catalogue, installed-part, stores, weapon, and
cost queries.

## Functions

| Function | Description |
| --- | --- |
| [`add_stores`](add-stores/) / [`remove_stores`](remove-stores/) | Changes stored part quantities. |
| [`categories`](categories/) | Lists canonical part categories. |
| [`cost`](cost/) / [`set_cost`](set-cost/) | Gets or sets configured part cost. |
| [`installed`](installed/) / [`installed_ref`](installed-ref/) | Lists installed parts. |
| [`list`](list/) | Lists canonical part names in a category. |
| [`match`](match/) | Finds packed part IDs matching text. |
| [`name`](name/) | Returns a packed part ID's name. |
| [`stores`](stores/) / [`stores_short`](stores-short/) | Queries stored parts. |
| [`type`](type/) | Returns a part's broad category. |
| [`weapon_stat`](weapon-stat/) | Returns a weapon-catalog statistic. |
| [`weight`](weight/) | Returns a part's weight in tons. |
