Returns one stored part quantity.

## Function

### Synopsis

```lua
btech.parts.store_quantity( target, part )
```

### Arguments

`DbRef|Object target`
: The stores-bearing object.

`BtechPartRef part`
: A part record, packed ID, or unique name.

### Returns

`integer quantity`
: The stored quantity.
