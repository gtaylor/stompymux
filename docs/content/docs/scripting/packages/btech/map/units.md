List units placed on a map in saved slot order; an optional filter omits distant units.

## Signature

```lua
btech.map.units(map, filter)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `map` | `DbRef\|Object` |  |
| `filter?` | `BattleMapUnitFilter` |  |

## Returns

- `Object[] units`
