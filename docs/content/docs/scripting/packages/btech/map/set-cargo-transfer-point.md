Sets or clears a map's cargo-transfer point.

## Function

### Synopsis

```lua
btech.map.set_cargo_transfer_point( map, point )
```

### Arguments

`DbRef|Object map`
: The BattleTech map.

`BtechCargoTransferPoint|nil point`
: The new point, or `nil` to clear it.

### Returns

None.
