Returns the terrain type of a map hex.

## Function

### Synopsis

```lua
btech.map.terrain( map, hex )
```

### Arguments

`DbRef|Object map`
: The BattleTech map.

`BtechHex hex`
: The zero-based map coordinates.

### Returns

`BtechTerrain terrain`
: The canonical terrain name.
