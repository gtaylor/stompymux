Returns a child map's parent-link configuration.

## Function

### Synopsis

```lua
btech.map.link( child )
```

### Arguments

`DbRef|Object child`
: The child BattleTech map.

### Returns

`BtechMapLink|nil link`
: The parent link, or `nil` when unset.
