Tests whether a map hex lies in a configured blast zone.

## Function

### Synopsis

```lua
btech.map.in_blast_zone( map, hex )
```

### Arguments

`DbRef|Object map`
: The BattleTech map.

`BtechHex hex`
: The zero-based map coordinates.

### Returns

`boolean inside`
: Whether the hex lies in a blast zone.
