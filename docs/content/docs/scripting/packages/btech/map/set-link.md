Sets or clears a child map's parent-link configuration.

## Function

### Synopsis

```lua
btech.map.set_link( child, link )
```

### Arguments

`DbRef|Object child`
: The child BattleTech map.

`BtechMapLink|nil link`
: The new parent link, or `nil` to clear it.

### Returns

None.
