Lists the blast zones configured on a map.

## Function

### Synopsis

```lua
btech.map.blast_zones( map )
```

### Arguments

`DbRef|Object map`
: The BattleTech map.

### Returns

`BtechBlastZone[] zones`
: The configured blast zones.
