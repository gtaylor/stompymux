Returns a map's cargo-transfer point.

## Function

### Synopsis

```lua
btech.map.cargo_transfer_point( map )
```

### Arguments

`DbRef|Object map`
: The BattleTech map.

### Returns

`BtechCargoTransferPoint|nil point`
: The configured point, or `nil` when unset.
