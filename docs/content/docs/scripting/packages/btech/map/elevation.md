Returns the elevation of a map hex.

## Function

### Synopsis

```lua
btech.map.elevation( map, hex )
```

### Arguments

`DbRef|Object map`
: The BattleTech map.

`BtechHex hex`
: The zero-based map coordinates.

### Returns

`integer elevation`
: The hex elevation.
