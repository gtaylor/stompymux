Places a live unit at a position on a map.

## Function

### Synopsis

```lua
btech.map.place_unit( unit, map, position )
```

### Arguments

`DbRef|Object unit`
: The live unit.

`DbRef|Object map`
: The destination BattleTech map.

`BtechPosition position`
: The zero-based coordinates and optional altitude.

### Returns

None.
