Returns a player's personal-combat loadout.

## Function

### Synopsis

```lua
btech.player.loadout( player )
```

### Arguments

`DbRef|Object player`
: The player.

### Returns

`BtechPersonalCombatLoadout|nil loadout`
: The loadout, or `nil` when unset.
