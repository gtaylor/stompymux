Sets or clears a player's personal-combat loadout.

## Function

### Synopsis

```lua
btech.player.set_loadout( player, loadout )
```

### Arguments

`DbRef|Object player`
: The player.

`BtechPersonalCombatLoadout|nil loadout`
: The new loadout, or `nil` to clear it.

### Returns

None.
