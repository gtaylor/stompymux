Sets or clears a player's ejected-pilot template override.

## Function

### Synopsis

```lua
btech.player.set_mechwarrior_template( player, reference )
```

### Arguments

`DbRef|Object player`
: The player.

`string|nil reference`
: The template reference, or `nil` to clear it.

### Returns

None.
