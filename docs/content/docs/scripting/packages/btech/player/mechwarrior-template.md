Returns a player's ejected-pilot template override.

## Function

### Synopsis

```lua
btech.player.mechwarrior_template( player )
```

### Arguments

`DbRef|Object player`
: The player.

### Returns

`string|nil reference`
: The template reference, or `nil` when unset.
