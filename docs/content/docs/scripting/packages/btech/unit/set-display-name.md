Sets or clears a live unit's display-name override.

## Function

### Synopsis

```lua
btech.unit.set_display_name( unit, name )
```

### Arguments

`DbRef|Object unit`
: The live unit.

`string|nil name`
: The display name, or `nil` to clear it.

### Returns

None.
