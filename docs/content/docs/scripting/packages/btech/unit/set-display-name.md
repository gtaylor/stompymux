Replace the saved display-name override; nil or an empty string clears it.

## Signature

```lua
btech.unit.set_display_name(unit, name)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `unit` | `DbRef\|Object` | Constructed unit. |
| `name` | `string\|nil` | At most 120 bytes. |

## Returns

No values.
