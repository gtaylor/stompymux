---
title: "btech.unit.hide"
type: docs
---

Begin hiding in forest, mountains or rough terrain; requires camouflage equipment or a wizard pilot.
Hostile acquired contacts or leaving the ground stop preparation. Hex crossings and firing cancel it.

## Signature

```lua
btech.unit.hide(dbref, pilot)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `dbref` | `integer` | Supported unit dbref. |
| `pilot` | `integer` | Assigned pilot. |

## Returns

- `boolean accepted Timer and cockpit feedback commit with the callback.`
