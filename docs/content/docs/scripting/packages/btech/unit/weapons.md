Lists the weapons mounted on a live unit.

## Function

### Synopsis

```lua
btech.unit.weapons( unit, section )
```

### Arguments

`DbRef|Object unit`
: The live unit.

`string|nil section`
: An optional class-specific section name or abbreviation.

### Returns

`BtechMountedWeapon[] weapons`
: The mounted weapons.
