List mounted weapons in mounting order; an optional section restricts the result.

## Signature

```lua
btech.unit.weapons(unit, section)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `unit` | `DbRef\|Object` |  |
| `section?` | `MechSection` | Typed section constant from btech.unit.sections. |

## Returns

- `MountedWeapon[]`
