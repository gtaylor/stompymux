Lists all operational parts installed on a live unit.

## Function

### Synopsis

```lua
btech.unit.installed_parts( unit )
```

### Arguments

`DbRef|Object unit`
: The live unit.

### Returns

`BtechPartStack[] parts`
: The installed parts and quantities.
