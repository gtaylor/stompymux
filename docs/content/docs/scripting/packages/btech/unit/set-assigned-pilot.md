Sets or clears a live unit's assigned pilot.

## Function

### Synopsis

```lua
btech.unit.set_assigned_pilot( unit, pilot )
```

### Arguments

`DbRef|Object unit`
: The live unit.

`DbRef|Object|nil pilot`
: The pilot, or `nil` to clear the assignment.

### Returns

None.
