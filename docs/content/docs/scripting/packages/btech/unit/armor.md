Returns a live unit's armor and internal values.

## Function

### Synopsis

```lua
btech.unit.armor( unit, section )
```

### Arguments

`DbRef|Object unit`
: The live unit.

`string|nil section`
: An optional class-specific section name or abbreviation.

### Returns

`BtechArmorStatus status`
: The requested armor status.
