Read current, original and rear armor values; an omitted section reports the totals.

## Signature

```lua
btech.unit.armor(unit, section)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `unit` | `DbRef\|Object` |  |
| `section?` | `UnitSection` | Typed section constant from btech.unit.sections. |

## Returns

- `ArmorStatus status`
