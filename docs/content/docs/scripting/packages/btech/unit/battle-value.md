Calculates a live unit's current battle value.

## Function

### Synopsis

```lua
btech.unit.battle_value( unit )
```

### Arguments

`DbRef|Object unit`
: The live unit.

### Returns

`BtechBattleValue value`
: The total, offensive, and defensive values.
