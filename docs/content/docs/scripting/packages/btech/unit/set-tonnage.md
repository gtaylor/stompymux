Sets a live unit's tonnage and original weight.

## Function

### Synopsis

```lua
btech.unit.set_tonnage( unit, tons )
```

### Arguments

`DbRef|Object unit`
: The live unit.

`integer tons`
: The positive tonnage.

### Returns

None.
