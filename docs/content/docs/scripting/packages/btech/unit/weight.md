Wizard-only construction allocation using original components and installed ammunition bins.

## Signature

```lua
btech.unit.weight(actor, unit)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `actor` | `integer` | Recipient; requires wizard authority. |
| `unit` | `integer` | Power, pilot assignment and placement are not required. |

## Returns

- `string report Publishes privately and returns formatted weight rows and total.`
