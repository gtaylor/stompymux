Lists a live unit's operational weapons and ammunition.

## Function

### Synopsis

```lua
btech.unit.payload( unit )
```

### Arguments

`DbRef|Object unit`
: The live unit.

### Returns

`BtechPartStack[] parts`
: The payload parts and quantities.
