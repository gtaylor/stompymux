```lua
btech.unit.critical_slots(unit, section)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `unit` | `DbRef\|Object` |  |
| `section` | `BattleSection` | Typed section constant from btech.unit.sections. |

## Returns

- `BattleCriticalSlot[] slots`
