Returns a live unit's assigned pilot.

## Function

### Synopsis

```lua
btech.unit.assigned_pilot( unit )
```

### Arguments

`DbRef|Object unit`
: The live unit.

### Returns

`Object|nil pilot`
: The pilot, or `nil` when none is assigned.
