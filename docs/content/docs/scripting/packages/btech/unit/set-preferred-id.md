Sets or clears a live unit's preferred tactical ID.

## Function

### Synopsis

```lua
btech.unit.set_preferred_id( unit, id )
```

### Arguments

`DbRef|Object unit`
: The live unit.

`string|nil id`
: The tactical ID, or `nil` to clear it.

### Returns

None.
