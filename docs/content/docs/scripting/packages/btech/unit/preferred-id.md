Returns a live unit's preferred tactical ID.

## Function

### Synopsis

```lua
btech.unit.preferred_id( unit )
```

### Arguments

`DbRef|Object unit`
: The live unit.

### Returns

`string|nil id`
: The ID, or `nil` when unset.
