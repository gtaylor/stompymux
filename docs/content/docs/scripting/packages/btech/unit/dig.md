Begin twenty seconds of digging in a stopped tracked or wheeled vehicle.
Completed cover permits only turret weapons; requesting movement leaves cover.

## Signature

```lua
btech.unit.dig(dbref, pilot)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `dbref` | `integer` |  |
| `pilot` | `integer` | Conscious assigned pilot; scripts own authority to act for them. |

## Returns

- `boolean`
