Sets a live unit's maximum speed.

## Function

### Synopsis

```lua
btech.unit.set_max_speed( unit, speed )
```

### Arguments

`DbRef|Object unit`
: The live unit.

`number speed`
: The new non-negative maximum speed.

### Returns

None.
