Attach a paused ground autopilot controller to a supported Mech or ground vehicle.

## Signature

```lua
btech.autopilot.attach(unit, options)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `unit` | `integer` | The unit to control. |
| `options` | `BattleAutopilotConfigPatch` | Optional initial configuration. |

## Returns

No values.
