Detach the unit's controller, stop autonomous movement, and clear its durable state.

## Signature

```lua
btech.autopilot.detach(unit)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `unit` | `integer` | The controlled unit. |

## Returns

No values.
