Tests whether a live unit has an active repair event.

## Function

### Synopsis

```lua
btech.repair.is_under_repair( unit )
```

### Arguments

`DbRef|Object unit`
: The live unit.

### Returns

`boolean under_repair`
: Whether the unit is under repair.
