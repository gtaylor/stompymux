Lists the repairs needed by a live unit.

## Function

### Synopsis

```lua
btech.repair.needs( unit )
```

### Arguments

`DbRef|Object unit`
: The live unit.

### Returns

`BtechRepairNeed[] needs`
: The required and in-progress repair operations.
