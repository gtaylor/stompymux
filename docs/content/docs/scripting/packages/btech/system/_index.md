`btech.system` provides generic special-object fields and server-wide
BattleTech queries.

## Functions

| Function | Description |
| --- | --- |
| [`design_exists`](design-exists/) | Tests whether a unit template exists. |
| [`lag`](lag/) | Returns current BattleTech event lag. |
| [`set_xcode_value`](set-xcode-value/) | Writes a script-visible native field. |
| [`xcode_value`](xcode-value/) / [`xcode_value_ref`](xcode-value-ref/) | Reads a script-visible native field. |
| [`zone_units`](zone-units/) | Lists live units assigned to a zone. |
