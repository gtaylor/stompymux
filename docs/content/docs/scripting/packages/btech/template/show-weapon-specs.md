Sends a template's weapon-specification report to a player.

## Function

### Synopsis

```lua
btech.template.show_weapon_specs( reference, player )
```

### Arguments

`string reference`
: The unit-template reference.

`DbRef|Object player`
: The report recipient.

### Returns

None.
