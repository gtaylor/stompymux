Lists the weapons mounted on a unit template.

## Function

### Synopsis

```lua
btech.template.weapons( reference, section )
```

### Arguments

`string reference`
: The unit-template reference.

`string|nil section`
: An optional class-specific section name or abbreviation.

### Returns

`BtechMountedWeapon[] weapons`
: The mounted weapons.
