Wraps text in markup described by the supplied style options.

Raises `mux.error.codes.text.invalid`.

## Signature

```lua
mux.text.style(value, options)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `value` | `string` |  |
| `options` | `StyleOptions` |  |

## Returns

- `string styled`

## Related errors

- `mux.error.codes.text.invalid`
