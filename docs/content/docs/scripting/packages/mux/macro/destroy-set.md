Destroy a set and clear every attachment to it.
Requires an active callback transaction; bypasses player permission checks.

## Signature

```lua
mux.macro.destroy_set(set)
```

| Name | Type | Description |
| --- | --- | --- |
| `set` | `MacroSet` |  |

## Returns

No values.
