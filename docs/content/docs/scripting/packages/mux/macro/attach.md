Attach to the first free slot without changing editing selection.
Requires an active callback transaction; bypasses player permission checks.

## Signature

```lua
mux.macro.attach(player, set)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `player` | `DbRef\|Object` |  |
| `set` | `MacroSet` |  |

## Returns

- `integer slot`
