Set any live object as owner.
Requires an active callback transaction and a live handle.

## Signature

```lua
MacroSet:set_owner(owner)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `owner` | `DbRef\|Object` |  |

## Returns

No values.
