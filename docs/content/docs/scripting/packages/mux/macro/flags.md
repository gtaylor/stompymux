Immutable typed constants available in the Stompymux-rs Lua runtime.

| Constant | Type or native code | Description |
| --- | --- | --- |
| `mux.macro.flags.LOCKED` | `MacroFlag` | Blocks player definition edits and renaming, including by the owner. |
| `mux.macro.flags.READ` | `MacroFlag` | Allows other players to discover, inspect, and attach the set. |
| `mux.macro.flags.WRITE` | `MacroFlag` | Allows other players to edit the unlocked set. |
