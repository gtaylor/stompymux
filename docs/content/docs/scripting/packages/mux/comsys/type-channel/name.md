---
title: "Channel:name"
type: docs
---

Returns the channel's exact name.

Raises `mux.error.codes.unavailable.checking` or `mux.error.codes.channel.invalid`.

## Signature

```lua
Channel:name()
```

## Parameters

None.

## Returns

- `string name`

## Related errors

- `mux.error.codes.unavailable.checking`
- `mux.error.codes.channel.invalid`
