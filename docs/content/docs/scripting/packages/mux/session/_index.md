`mux.session` provides interactive-flow controls and non-privileged information
about active player sessions.

## Functions

| Function | Description |
| --- | --- |
| [`connected_players`](connected-players/) | Lists player connections visible to the normal `who` command. |
| [`flow_start`](flow-start/) | Starts an interactive flow on a descriptor. |
| [`who_summary`](who-summary/) | Returns the non-privileged WHO summary. |
