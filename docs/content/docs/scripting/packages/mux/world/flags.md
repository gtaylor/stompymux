Immutable typed constants available in the Stompymux-rs Lua runtime.

| Constant | Type or native code | Description |
| --- | --- | --- |
| `mux.world.flags.ANSI` | `Flag` | Enables ANSI-capable output for the object. |
| `mux.world.flags.AUDIBLE` | `Flag` | Enables sound-capable notifications associated with the object. |
| `mux.world.flags.AUDITORIUM` | `Flag` | Applies auditorium-style speech propagation. |
| `mux.world.flags.BLIND` | `Flag` | Marks the object as unable to see normally. |
| `mux.world.flags.CONNECTED` | `Flag` | Marks a player as currently connected. |
| `mux.world.flags.DARK` | `Flag` | Hides the object according to native visibility rules. |
| `mux.world.flags.FLOATING` | `Flag` | Prevents ordinary location inheritance for the object. |
| `mux.world.flags.GAGGED` | `Flag` | Prevents the object from speaking normally. |
| `mux.world.flags.GOING` | `Flag` | Marks the object for deferred destruction. |
| `mux.world.flags.HALTED` | `Flag` | Prevents queued command execution by the object. |
| `mux.world.flags.IN_CHARACTER` | `Flag` | Marks the object as participating in in-character play. |
| `mux.world.flags.LIGHT` | `Flag` | Makes the object visible through native light rules. |
| `mux.world.flags.MONITOR` | `Flag` | Enables command monitoring behavior. |
| `mux.world.flags.NO_COMMAND` | `Flag` | Excludes commands stored on the object from command matching. |
| `mux.world.flags.SAFE` | `Flag` | Protects the object from ordinary destruction. |
| `mux.world.flags.SUSPECT` | `Flag` | Marks a player for suspect-activity monitoring. |
| `mux.world.flags.TRANSPARENT` | `Flag` | Allows visibility through the object. |
| `mux.world.flags.WIZARD` | `Flag` | Grants Wizard status under native privilege rules. |
| `mux.world.flags.ZOMBIE` | `Flag` | Allows a thing to act through its owner under native rules. |
