Raises `mux.error.codes.object.invalid`, `mux.error.codes.state.unavailable`.

## Signature

```lua
State:entries()
```

## Parameters

None.

## Returns

- `StateEntry[] entries`

## Related errors

- `mux.error.codes.object.invalid`
- `mux.error.codes.state.unavailable`
