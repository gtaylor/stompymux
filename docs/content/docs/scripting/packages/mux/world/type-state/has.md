Tests whether a state key is present.

Raises `mux.error.codes.object.invalid`, `mux.error.codes.state.invalid`.

## Signature

```lua
State:has(key)
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `key` | `string` |  |

## Returns

- `boolean exists`

## Related errors

- `mux.error.codes.object.invalid`
- `mux.error.codes.state.invalid`
