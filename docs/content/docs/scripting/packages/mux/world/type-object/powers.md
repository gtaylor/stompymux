Creates a handle for this object's powers.

Raises `mux.error.codes.object.invalid` or `mux.error.codes.unavailable.checking`.

## Signature

```lua
Object:powers()
```

## Parameters

None.

## Returns

- `Powers powers`

## Related errors

- `mux.error.codes.object.invalid`
- `mux.error.codes.unavailable.checking`
