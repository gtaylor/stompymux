`mapgen` generates battlefield [map files](../map-files/) from a short
description: a biome, a size, how much water, woods and rough ground, rivers,
settlements and roads. The generator is the `stompymux-mapgen` library in
`crates/mapgen`. It does not depend on the server, so map editors can embed it;
the `mapgen` command-line tool is a thin wrapper around it.

## Quick start

```sh
just mapgen generate --biome temperate --size medium \
    --settlement town@center --settlement village,count=2 \
    -o game/maps/farmland.toml
```

`just mapgen` is `cargo run -p stompymux-mapgen --bin mapgen --`. Without `-o`
the map file goes to standard output. `--report FILE` writes a JSON summary of
what was built (`-` prints it to standard error).

Generation is deterministic: the same description and `--seed` always produce
the same map. When no seed is given, one is picked at random. The first lines
of every generated file are a comment holding the fully resolved description,
seed included:

```toml
# Generated by stompymux mapgen. The spec below regenerates this map exactly.
# mapgen-spec: {"seed":1234,"biome":"temperate","width":50,...}
```

Copy that JSON into a file and pass it to `--spec` to regenerate the map, or
change a field first to get a variation of it. The game ignores the comment, and
`SAVEMAP` does not keep it.

## Commands

| Command | Does |
| --- | --- |
| `mapgen generate [FLAGS]` | Generate a map file. |
| `mapgen schema` | Print the JSON Schema for map specs. |
| `mapgen biomes [--json]` | List every biome with its description and defaults. |

## Describing a map

Every setting is optional. A setting you leave out takes the biome's default.

| Flag | Spec field | Values |
| --- | --- | --- |
| `--seed N` | `seed` | Any unsigned 64-bit number. |
| `--biome B` | `biome` | See [Biomes](#biomes). Default `temperate`. |
| `--size S` | `size` | `small` (30×30), `medium` (50×50, default), `large` (80×80), `huge` (120×120). |
| `--width N`, `--height N` | `width`, `height` | 8 to 1000 hexes; override `size`. |
| `--relief R` | `relief` | `flat` (levels 0–2), `rolling` (0–4), `hilly` (0–8), `mountainous` (0–16). |
| `--water A` | `water` | An amount: `none`, `low`, `medium`, `high` or `extreme`. Roughly 0, 5, 15, 30 and 50% of the map. |
| `--woods A` | `woods` | An amount of woods (jungle in the `jungle` biome). Roughly 0, 10, 25, 45 and 70% of the land. |
| `--rough A` | `rough` | An amount. Roughly 0, 5, 12, 25 and 40% of the land. |
| `--fire A` | `fire` | An amount of permanent fire and smoke. Roughly 0, 1, 3, 6 and 12% of the map. |
| `--rivers N` | `rivers` | 0 to 8 rivers crossing the map. |
| `--frozen BOOL` | `frozen` | Lay the ice condition over every lake and river, bridged or not. |
| `--settlement SPEC` | `settlements` | Repeatable; see [Settlements](#settlements). |
| `--through-roads N` | `roads.through_roads` | 0 to 8 highways crossing the map edge to edge. Default 1 when there are settlements. |
| `--no-connecting-roads` | `roads.connect_settlements` | Do not link settlements with roads. |
| `--road-width N` | `roads.width` | 1 to 3 hexes. |
| `--gravity N` | `environment.gravity` | Percent of standard. |
| `--temperature N` | `environment.temperature` | Degrees Celsius. |
| `--flag F` | `environment.flags` | Repeatable map flag, such as `dark` or `vacuum`. Replaces the biome's flags. |

`--spec FILE` reads a JSON or TOML spec (`-` reads standard input).
Flags override the matching spec fields, and `--settlement` flags add to the
spec's settlements.

```json
{
  "biome": "desert",
  "size": "large",
  "relief": "hilly",
  "settlements": [
    { "size": "city", "position": "center", "walled": true, "name": "Oasis" },
    { "size": "outpost", "kind": "military", "count": 3 }
  ],
  "roads": { "width": 2 }
}
```

## Biomes

| Biome | Relief | Water | Woods | Rough | Rivers | Gravity | °C | Flags |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `temperate` | rolling | low | medium | low | 1 | 100 | 20 | — |
| `forest` | rolling | low | high | low | 1 | 100 | 20 | — |
| `jungle` | hilly | medium | extreme | low | 2 | 100 | 35 | — |
| `desert` | rolling | none | none | medium | 0 | 100 | 45 | — |
| `arctic` | rolling | medium | low | low | 1 | 100 | -30 | — |
| `mountains` | mountainous | low | medium | medium | 1 | 100 | 5 | — |
| `badlands` | hilly | none | none | high | 1 | 100 | 35 | — |
| `swamp` | flat | high | high | none | 2 | 100 | 28 | — |
| `coastal` | rolling | high | low | low | 1 | 100 | 20 | — |
| `lunar` | rolling | none | none | high | 0 | 17 | -120 | `vacuum` |
| `volcanic` | hilly | none | low | high | 0 | 100 | 40 | — |

Biomes also shape the land in ways no flag controls:

- **Desert** and **badlands** open ground is sand. Badlands are terraced into
  mesas.
- **Arctic** open ground is tundra. Snowfields cover most of the land, woods
  and rough ground included. Most of it is deep snow, with patches of thin
  snow. Lakes and rivers freeze over.
- **Mountains** have ridgelines and ultra-rough peaks. Deep snow lies over
  everything at and above the snow line, which is 60% of the way up the
  relief. The level just below it gets thin snow.
- **Jungle** trees are light, heavy and ultra-heavy jungle rather than woods.
  **Forest** has stands of ultra-heavy woods among its light and heavy woods.
- **Swamp** maps are flat and pocked with shallow pools. Their low, wet ground
  is swamp, and woods can grow on it.
- **Coastal** maps slope down to a sea along one edge, with beaches.
- **Lunar** maps are cratered.
- **Volcanic** maps have a cone with a caldera that burns hottest near the
  summit.
- In **temperate**, **forest**, **mountains** and **coastal** maps, civilian
  settlements are ringed by planted fields.

## What a generated map holds

Generated maps use the same hex layers as every other [map file](../map-files/):

| Layer | What mapgen puts there |
| --- | --- |
| Ground | Clear, sand or tundra open ground, rough ground, ultra-rough peaks, swamp, pavement in settlements, and rubble in ruins. |
| Water | Seas, lakes and rivers. A river runs as rapids where its surface drops a level, and as a torrent where it drops two or more. |
| Foliage | Light, heavy and ultra-heavy woods or jungle, park trees, and planted fields around farming settlements. Woods never share a hex with rough ground. |
| Route | Paved streets and highways, and gravel or dirt roads between settlements. |
| Structure | Buildings, walls and bridges, each with a construction class. |
| Condition | Deep and thin snow, and ice over frozen water. |
| Overlay | Permanent fire and smoke. |

Generated maps leave light, visibility and wind unset, so loading one keeps the
live map's current values.

Each settlement is also marked for scripts. The map gets a
[point of interest](../map-files/#points-of-interest) at the settlement's center
and a [region](../map-files/#regions) holding exactly the hexes the settlement
covers, both of type `settlement` and named after the settlement (its `name`,
or its size and number, such as `village 2`).

## Settlements

A settlement is a cluster of buildings with its own streets. On the command line
it is `SIZE[@POSITION][,OPTION...]`:

```sh
--settlement city@center,walled
--settlement village,count=3,kind=ruins
--settlement outpost@northeast,kind=military,name=Firebase
--settlement town,at=40:12,layout=organic
```

| Setting | Option | Values |
| --- | --- | --- |
| `size` | (first word) | `outpost`, `hamlet`, `village`, `town`, `city`, `metropolis`; from about 5 to about 37 hexes across. Larger settlements have taller buildings. |
| `position` | `@POSITION` | `center`, `north`, `northeast`, `east`, `southeast`, `south`, `southwest`, `west`, `northwest`, or `random` (default). |
| `at` | `at=X:Y` | An exact center hex; overrides `position`. |
| `kind` | `kind=` | `civilian` (default; buildings rise toward a downtown), `industrial` (large, low, dense blocks), `military` (a walled compound with a landing pad), `ruins` (rubble, broken walls, smoke). |
| `layout` | `layout=` | `grid` (street grid), `organic` (winding streets from a square), `scattered` (spread-out buildings), `compound` (perimeter road and rows of buildings). Defaults by size and kind. |
| `walled` | `walled`, `open` | A wall around the edge with a gate on each side. Military settlements are walled by default. |
| `count` | `count=` | Place 1 to 32 alike. |
| `name` | `name=` | A label for the report. |

Each settlement is placed on the flattest, driest ground near its requested
position, away from other settlements. Its site is levelled and blended into
the surrounding land. Streets that cross water become bridges. A settlement too
large for the map is shrunk to fit, with a warning.

Streets are paved roads. Towns and larger, industrial estates and military
bases also pave their open lots. Streets, buildings and walls are kept clear of
snow. Snow still lies in yards and parks. Construction classes suit the
settlement:

| Structure | Class |
| --- | --- |
| Buildings two levels or lower in hamlets, villages and outposts | Light |
| Other civilian buildings | Medium; heavy at eight levels or taller |
| Industrial buildings | Medium; heavy at three levels or taller |
| Military buildings | Heavy |
| Walls | Heavy; hardened around military bases |
| Settlement bridges | Heavy in paved settlements, medium elsewhere |

Ruins leave rubble where buildings, walls and streets fell. Their remaining
buildings and walls have lost a third to nine tenths of their construction
factor.

## Roads

Roads link every settlement into one network using the shortest set of links.
Through roads are highways from one map edge to the opposite edge that run
through settlements on their way. Roads avoid steep climbs, dense woods and
jungle, swamp, ultra-rough peaks and deep water. They share existing roads
where they can, and bridge the water they must cross.

A road is a route laid through the hexes it crosses. Woods, rough ground and
fields stay in place under it, and units travelling along the road pay only for
the road. Roads are kept clear of snow.

| Road | Surface |
| --- | --- |
| Through roads | Paved |
| Links where both settlements are towns or larger, or one is a military base | Gravel |
| Other links | Dirt |

Where roads overlap, the better surface wins. Bridges suit the road: heavy for
paved roads, medium for gravel and light for dirt. The report gives each road's
surface.

## Generating in Mappy

Mappy's **Map ▸ Map generator…** (Ctrl+G) opens the generator in the side
panel. It offers every option above: biome, size, seed, relief, water, woods,
rough ground, fire, rivers, freezing, a list of settlements, and roads. Options
left at **Default** show the value the biome picks, and settlement options left
at **Auto** are chosen where the settlement is placed.

Every change regenerates the map in the background and shows it on the canvas
in place of the open map. A blank seed gets a new random one, which then fills
the seed field, so later changes keep the same landscape until **New seed** is
pressed. **Apply** replaces the open map's size, hexes, gravity, temperature and
flags as one step that undo reverses; light, visibility and wind are kept. Points
of interest and region corners still on the map are kept too, except those of
type `settlement` from an earlier generation, which give way to the new map's
settlement points and regions. **Cancel** or Escape goes back to the map as
it was. The menus, brushes and undo wait while the generator is open.

Mappy saves the generator's spec in the map file's header, and reopening the
generator on that map starts from the same spec. The header reads
`# Generated by stompymux mapgen from the spec below, then edited in Mappy.`,
since hand edits after applying are not part of the spec.

## Using it from an LLM

`mapgen schema` prints a JSON Schema whose descriptions explain every field, so
it can be used directly as an LLM tool's input schema. Write the tool's result
to a file and run `mapgen generate --spec FILE --report -`. The report lists
the terrain mix, each settlement's center, size and building count, the roads
and their surfaces, and warnings for anything that could not be done exactly.
The model can check the result against the spec and adjust it. The terrain mix
gives the percent of hexes holding each ground, water, foliage, road surface,
structure and snow. Layers overlap, so a snowy wood counts toward its ground,
its woods and its snow. The ground percentages and `water` add up to 100.

## Embedding

```rust
use stompymux_mapgen::{Biome, MapSpec, SettlementSize, SettlementSpec, generate};

let generated = generate(&MapSpec {
    biome: Some(Biome::Forest),
    settlements: vec![SettlementSpec::new(SettlementSize::Town)],
    ..MapSpec::default()
})?;
let hex = generated.map.hex(10, 4); // a stompymux_map::Hex with all its layers
let file = generated.to_toml()?;
```

Depend on the crate with `default-features = false` to leave out the
command-line tool and its dependencies. `stompymux_mapgen::embedded_spec` reads
the spec back out of a generated map file, so an editor can reopen a map with
its original settings, and `stompymux_mapgen::embed_spec` writes one into a map
file the editor saves.
