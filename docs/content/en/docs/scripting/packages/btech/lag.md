# `btech.lag`

Returns the current BattleTech event lag.

## Function

### Synopsis

```lua
btech.lag(  )
```

### Arguments

None.

### Returns

`number value`
: The numeric result.

## Notes

This function is available only in a running Lua callback. Invalid targets, invalid arguments, and legacy error results raise a Lua error.
