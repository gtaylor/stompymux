# +rolls

`+rolls` displays the count and percentage for each generic two-die result,
the expected distribution, and the chance of meeting or missing each target.
Only wizards can use this command. It has no switches.

The report includes committed generic checks from units and maps, including
checks made by units that have since been retired or deleted. Reading it does
not roll dice, drain counters or advance the game. Statistics reset on restart.

Direct dice, such as character consciousness checks, single-die location rolls
and hotloaded three-die cluster checks, are not part of this histogram.
